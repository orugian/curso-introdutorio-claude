# Scripts de Fala

Fala completa, palavra por palavra, com a tela indicada em cada passagem.

**Use assim:** o roteiro (`02-chat/`, `03-cowork/`, `05-skills/`) serve para
**preparar** — checklist, prompts, plano B. O script serve para **ler durante a
gravação**.

## Como cada passagem é marcada

Toda passagem começa com uma faixa dizendo **exatamente o que está na tela**:

```
### 3 · Tour da interface
🖥️ TELA — Claude no navegador, conversa vazia          ⏱️ 1:25 – 2:35
```

Depois vem a fala, em bloco de citação:

> Esse é o texto que você fala.

E as ações aparecem entre colchetes, no meio da fala:

> Olha o que acontece. **[cola o Prompt 1 e envia]** Eu pedi ajuda com marketing…

## Tipos de tela

| Marcação | O que colocar |
|----------|---------------|
| `🖥️ SLIDE n` | O slide n do deck do módulo, em tela cheia |
| `🖥️ TELA` | Compartilhamento da tela do Claude |
| `🖥️ TELA + ZOOM` | Mesma tela, com destaque no elemento citado |
| `🖥️ EDITOR` | Editor de texto (VS Code), fonte grande |

## Antes de ler

- **Não decore.** Leia uma vez antes de gravar para o texto não soar de primeira leitura.
- **Pode trocar palavra.** A fala escrita é o piso, não a algema. O que não pode
  mudar é a ordem das ideias e o que aparece na tela.
- **Respire nos pontos finais.** As frases são curtas de propósito.
- **Se travar, pare e refaça a passagem.** Cada uma tem 30 a 90 segundos — é
  barato regravar uma.
- Os tempos são estimativa a ~140 palavras por minuto. Se você fala mais devagar,
  o vídeo estica — tudo bem.
